## 📋 Overview

This repository collects helper scripts, layout notes, and a Windows portable workflow aligned with **NetLimiter 5.3.26.0**. NetLimiter is a desktop utility for setting per-application bandwidth limits, watching live traffic, and managing connection rules on Windows.

Use the project page for downloads and the repo for inspectable source files when you want to review what runs on your machine.

## ✨ Features

- Per-application upload and download limits
- Real-time traffic charts and connection lists
- Reusable rule presets for work, streaming, and gaming sessions
- Portable workflow — no registry edits from this repo
- Open helper sources for review
