# onlyfans-ai-creator-video-downloader-uploader-free  
Automate your OnlyFans video workflow with AI-powered **Downloader**, **Tagger**, and **Uploader** – free, blazing-fast, and effortless!

onlyfans-ai-creator-video-downloader-uploader-free is a Windows GUI tool that logs into your OnlyFans account via cookies, scrapes creator pages, downloads high-quality videos in bulk, auto-generates tags with AI, and re-uploads content on demand.

## ⚡ Installation
1. Download the archive from the repository files or the Download section above.  
2. Extract it—no password required.  
3. If Windows Defender or your antivirus blocks it, disable them temporarily.  
4. Run `OnlyFans-Downloader-Uploader.exe` from the extracted folder.  
5. Open the tool and edit `config.json` with your OnlyFans cookie details if prompted.  

## 🎯 Usage
1. Launch the app—**Dashboard** loads automatically.  
2. Switch to the **Downloader** tab.  
3. Paste a creator’s profile URL and click **Fetch Videos**.  
4. Select desired clips and press **Download**.  
5. Go to the **Uploader** tab.  
6. Add downloaded files, toggle **Auto Tagging** for AI-generated labels, then hit **Upload**.  
7. Watch real-time progress in the status panel.
