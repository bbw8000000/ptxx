# HTML Doc

AI가 편집 가능한 단독 HTML 문서를 만들도록 돕는 Agent Skills 패키지입니다.

English · AI용 지침 · 한국어 상세 가이드

보고서·안내문·레터를 HTML로 만들고, 브라우저에서 글자와 서식을 고치고 저장할 수 있습니다. 편집기 없는 배포본을 만들거나, 기존 HTML에 편집기를 붙일 수도 있습니다. 완성된 HTML을 사용하는 데 서버·확장 프로그램·AI 계정은 필요하지 않습니다.

현재 버전은 **1.5.0**입니다. AI용 공통 지침은 영어, 상세 가이드는 한국어입니다. 편집기와 변환 도구의 UI는 현재 한국어이며, 문서 본문은 원하는 언어로 작성할 수 있습니다.

## 바로 내려받기

최신 배포본 · 편집 가능한 예시 · 기존 HTML에 편집기 추가 도구

HTML 파일을 내려받아 브라우저로 열면 됩니다.

## 설치 없이 사용하기

저장소 또는 배포 ZIP 전체를 내려받아 압축을 풀고 다음 파일을 브라우저로 엽니다.

- `examples/demo.html`: 편집 기능이 포함된 예시.
- `assets/skeleton.html`: 새 문서를 만들 때 복사할 골격.
- `tools/add-editor.html`: 기존 HTML을 선택해 편집 가능한 사본으로 변환.

`*-src.html`은 빌드 입력이므로 완성된 `.html`을 여세요. GitHub의 소스 보기 화면에서는 편집기가 실행되지 않습니다.

## Claude Code·Codex 설치

`SKILL.md`만 복사하지 말고 **assets 등 모든 파일이 포함된 html-doc 폴더 전체**를 설치합니다.

| 환경 | 개인 설치 위치 | 호출 예시 |
|---|---|---|
| Claude Code | `~/.claude/skills/html-doc/` | `/html-doc 편집 가능한 보고서를 만들어줘` |
| Codex 로컬 | `~/.agents/skills/html-doc/` | `$html-doc 편집 가능한 보고서를 만들어줘` |
| 다른 Agent Skills 지원 도구 | 해당 제품의 스킬 설치 위치 | html-doc 사용을 요청 |

프로젝트 안에서만 사용할 때는 프로젝트의 `.claude/skills/` 또는 `.agents/skills/`에 넣습니다. 최종 경로가 `html-doc/SKILL.md`인지 확인하세요. ZIP에 바깥 폴더가 붙어 있으면 이름을 바꾸거나 내용을 복사합니다. 기존 설치가 있으면 내용을 확인한 뒤 업데이트하세요.

Git clone 설치 명령 예시는 영문 설치 안내에 있습니다. Codex에서는 스킬 설치 도구에 저장소 주소를 전달하는 방법도 있습니다. AI별 지원 기능·권한은 다르며, 이 저장소 자체가 제품별 플러그인 등록을 의미하지는 않습니다.

## 주요 기능과 저장 방식

- **편집:** 글꼴·크기·색·정렬·목록·표 등을 수정합니다.
- **저장:** 지원 브라우저에서 첫 저장 때 대상을 한 번 선택합니다. 이후 같은 경로·프로필에서는 연결을 기억할 수 있으며 권한 재확인이 필요할 수 있습니다.
- **다른 이름으로:** 새 저장 대상을 선택합니다. 파일 API 미지원 환경에서는 다운로드로 동작하며 창 표시 여부는 브라우저 설정을 따릅니다.
- **자동저장:** 브라우저 안의 백업입니다. 파일 저장과 다릅니다. ‘무시’는 일시적으로 닫고, ‘무시하고 현재 버전으로 백업 확정’은 이전 백업을 현재 본문으로 교체합니다.
- **배포용 HTML 저장:** 본문·디자인을 유지하고 편집기·히스토리를 제거한 별도 사본을 다운로드합니다.
- **HTML에 편집기 추가:** 다른 HTML을 편집 가능한 사본으로 만듭니다. 원본 파일을 덮어쓰지 않습니다.

모바일에서는 추가 기능이 **더보기** 안에 있으며 툴바를 좌우로 넘길 수 있습니다. 편집 전환은 `Cmd/Ctrl+E`, 저장은 `Cmd/Ctrl+S`입니다.

일반 저장 HTML에는 이전 본문이 히스토리로 남을 수 있습니다. 편집 히스토리를 제외한 공유 파일이 필요하면 배포용 저장을 사용하세요. 배포본에도 문서 자체 스크립트와 외부 리소스 참조는 유지됩니다. 스크립트 정화나 서버 게시 기능은 아닙니다.

자동 변환은 본문 컨테이너를 추가할 수 있어 `body > ...` 스타일이나 부모 구조에 의존하는 스크립트는 확인이 필요합니다. 상대 경로 이미지·CSS가 있으면 결과를 원본과 같은 폴더에 두세요. 모든 AI·브라우저에서 동일하게 동작한다고 보장하지 않습니다.

## 개발·검증

```sh
python3 assets/build-template.py
python3 scripts/check-release.py
python3 scripts/package-release.py
```

Python 3.9 이상은 재빌드·검증·ZIP 생성에만 필요합니다. 생성된 문서를 사용하는 사람에게는 필요하지 않습니다. 검증 안내의 Aside 회귀 테스트는 선택적인 개발 도구이며, 스킬 사용 조건은 아닙니다.

패키징 명령은 저장소 옆에 ZIP과 SHA-256 파일을 만듭니다. GitHub 업로드는 수행하지 않습니다.
