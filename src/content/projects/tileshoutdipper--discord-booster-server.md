## ✨ FEATURES

### 🔥 Auto Server Booster
Automatically applies Nitro boosts from multiple accounts to a target Discord server. Supports bulk boosting operations with configurable delays between each boost to avoid rate limits.

**Boost Settings:**
- Set number of boosts per account
- Configurable delay between boosts (2s–60s)
- Target server by invite link or server ID
- Real-time boost status monitoring
- Boost history log with timestamps

### 📥 Mass Server Joiner
Discord server joiner tool automates joining servers from invite links across all loaded accounts simultaneously or in sequence.

**Joiner Settings:**
- Import invite list from TXT file (one per line)
- Join delay randomization (human-like behavior)
- Skip already-joined servers automatically
- Retry failed joins up to 3 times
- Export join results to CSV report

### 👥 Multi-Account Manager
Load and manage hundreds of Discord accounts simultaneously with token-based authentication.

**Account Features:**
- Import tokens from TXT or CSV
- Token validator (removes invalid/banned tokens)
- Proxy assignment per account
- Account health check dashboard
- Automatic cookie and session handling

### 🌐 Proxy Support
Distribute requests across proxies to avoid IP-based rate limits.

**Supported Proxy Types:**
- HTTP / HTTPS
- SOCKS4 / SOCKS5
- Rotating proxy API support
- Proxy health checker built-in
- Auto-remove dead proxies

## 🔧 TROUBLESHOOTING

### Error: "Invalid token"
**Solution:** Re-export tokens from Discord sessions. Tokens expire or get invalidated after password changes. Use the built-in token validator before starting.

### Error: "Rate limited"
**Solution:** Increase join/boost delay in settings. Enable proxy rotation. Reduce concurrent thread count to 3–5.

### Error: "Failed to join server"
**Solution:** Check invite link is still valid and not expired. Server may have member restrictions or verification requirements. Try with a different account.

### Error: "Proxy connection refused"
**Solution:** Verify proxy credentials and format (`ip:port:user:pass`). Test proxies with built-in checker. Switch to SOCKS5 for better compatibility.

### Error: "Boost not applying"
**Solution:** Account must have active Nitro subscription for boosts to work. Verify Nitro status on each account before running boost campaign.
