# Discord Token Checker & Validator 2026

*图片：Windows*
*图片：Version*
*图片：License*
*图片：Downloads*

Bulk validates Discord tokens and returns account info: username, email, phone, Nitro status, billing, and server list. Outputs valid tokens to file.

## Features

- Checks token validity in bulk
- Returns username, email, phone, Nitro status
- Checks if billing is attached
- Lists servers the account is in
- Proxy support for mass checking
- Exports results as JSON or TXT

## FAQ

**How many tokens can it check per minute?**  
Around 300–600 per minute with 100 threads and proxy rotation.

**Does it work with user and bot tokens?**  
Yes — both user tokens and bot tokens are supported.
