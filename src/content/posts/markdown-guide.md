Markdown 是一种轻量级标记语言，让你专注于内容本身，而不是排版。

## 基础语法

### 标题

使用 `#` 号标记标题，一个 `#` 是一级标题，两个 `##` 是二级标题，以此类推。

### 强调

- **粗体** 使用 `**粗体**`
- *斜体* 使用 `*斜体*`
- ~~删除线~~ 使用 `~~删除线~~`

### 列表

无序列表：
- 第一项
- 第二项
  - 嵌套项目

有序列表：
1. 第一步
2. 第二步
3. 第三步

### 链接和图片

```markdown
[链接文字](https://example.com)
![图片描述](image.jpg)
```

### 引用

> 这是一段引用文字。可以用来标注出处或强调重要内容。

### 代码

行内代码使用反引号：`code`

代码块使用三个反引号：

```python
def hello():
    print("Hello, Markdown!")
```

### 表格

| 功能 | 语法 | 说明 |
|------|------|------|
| 标题 | `# H1` | 1-6 个 `#` |
| 粗体 | `**text**` | 双星号 |
| 链接 | `[text](url)` | 方括号+圆括号 |

## 写作建议

1. **保持简洁** — 用最少的文字表达最清楚的意思
2. **结构清晰** — 合理使用标题层级
3. **善用列表** — 让要点一目了然
4. **代码高亮** — 指定语言类型以获得语法高亮

Markdown 的美在于它的简单。掌握这些基础，你就可以开始高效写作了。
