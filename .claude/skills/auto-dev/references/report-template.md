# 开发报告模板

使用以下模板生成自动开发报告。根据实际执行情况填充各部分。

---

## 报告模板

```markdown
# 开发报告

**生成时间**：{当前时间}
**项目**：{项目名称}
**任务**：{用户描述的任务}

---

## 1. 项目概览

| 项目     | 详情                    |
| -------- | ----------------------- |
| 技术栈   | {检测到的技术栈}        |
| 框架     | {检测到的框架}          |
| 包管理器 | {检测到的包管理器}      |
| 项目类型 | {前端/后端/全栈/CLI/库} |

## 2. 任务摘要

**任务类型**：{新功能/Bug修复/重构/其他}

**任务描述**：
{用户的原始需求描述}

**实现方案**：
{简述采用的实现方案}

## 3. 变更详情

### 修改的文件

| 文件       | 变更类型         | 说明       |
| ---------- | ---------------- | ---------- |
| {文件路径} | {修改/新增/删除} | {变更说明} |

### 新增的文件

| 文件       | 用途       |
| ---------- | ---------- |
| {文件路径} | {文件用途} |

### 删除的文件

| 文件       | 原因       |
| ---------- | ---------- |
| {文件路径} | {删除原因} |

## 4. 验证结果

| 检查项   | 状态    | 详情                     |
| -------- | ------- | ------------------------ |
| 构建     | {✓/✗/—} | {构建结果}               |
| 测试     | {✓/✗/—} | {测试结果，通过率}       |
| Lint     | {✓/✗/—} | {Lint 结果，错误/警告数} |
| 类型检查 | {✓/✗/—} | {类型检查结果}           |

## 5. 审查结果

### 代码质量审查

| 严重级别 | 数量   | 说明   |
| -------- | ------ | ------ |
| CRITICAL | {数量} | {说明} |
| HIGH     | {数量} | {说明} |
| MEDIUM   | {数量} | {说明} |
| LOW      | {数量} | {说明} |

### 安全审查

| 问题       | 严重级别 | 状态            |
| ---------- | -------- | --------------- |
| {问题描述} | {级别}   | {已修复/待处理} |

## 6. 下一步建议

- {建议 1}
- {建议 2}
- {建议 3}

---

## 执行摘要

**总耗时**：{预估时间}
**完成状态**：{成功/部分成功/需要人工介入}
**风险提示**：{需要注意的风险点}
```

---

## 使用说明

1. 将模板中的 `{占位符}` 替换为实际内容
2. 删除不适用的部分（如没有安全审查则删除安全审查部分）
3. 根据实际情况调整表格内容
4. 如果某个检查被跳过，状态标记为 "—" 并说明原因

## 示例输出

```markdown
# 开发报告

**生成时间**：2026-05-27 14:30
**项目**：my-astro-blog
**任务**：添加搜索功能

---

## 1. 项目概览

| 项目     | 详情               |
| -------- | ------------------ |
| 技术栈   | TypeScript + Astro |
| 框架     | Astro v6           |
| 包管理器 | pnpm               |
| 项目类型 | 前端博客           |

## 2. 任务摘要

**任务类型**：新功能

**任务描述**：
给博客添加一个搜索功能，支持按标题和内容搜索文章。

**实现方案**：
使用 Fuse.js 实现客户端模糊搜索，创建 Search 组件集成到导航栏。

## 3. 变更详情

### 修改的文件

| 文件                     | 变更类型 | 说明                     |
| ------------------------ | -------- | ------------------------ |
| src/layouts/Layout.astro | 修改     | 添加 Search 组件到导航栏 |

### 新增的文件

| 文件                        | 用途     |
| --------------------------- | -------- |
| src/components/Search.astro | 搜索组件 |
| src/lib/search.ts           | 搜索逻辑 |

## 4. 验证结果

| 检查项   | 状态 | 详情             |
| -------- | ---- | ---------------- |
| 构建     | ✓    | 构建成功，无错误 |
| 测试     | —    | 未配置测试框架   |
| Lint     | ✓    | 无错误，2 个警告 |
| 类型检查 | ✓    | 类型检查通过     |

## 5. 审查结果

### 代码质量审查

| 严重级别 | 数量 | 说明                               |
| -------- | ---- | ---------------------------------- |
| CRITICAL | 0    | —                                  |
| HIGH     | 0    | —                                  |
| MEDIUM   | 1    | 搜索结果高亮函数可以提取为工具函数 |
| LOW      | 2    | 一些命名可以更 descriptive         |

## 6. 下一步建议

- 添加搜索结果高亮功能
- 考虑添加搜索历史记录
- 可以添加搜索统计（热门搜索词）

---

## 执行摘要

**总耗时**：约 15 分钟
**完成状态**：成功
**风险提示**：Fuse.js 是客户端搜索，大量文章时可能有性能问题
```
