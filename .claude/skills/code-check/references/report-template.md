## 简洁报告模板

适用于快速检查：

```markdown
# 快速代码审计

**项目**：{项目名称}
**时间**：{审计时间}

## 评分

整体评分：{总分}/100

| 维度 | 评分 |
|------|------|
| 代码质量 | {分数}/100 |
| 安全 | {分数}/100 |
| 性能 | {分数}/100 |
| 测试 | {分数}/100 |
| 最佳实践 | {分数}/100 |

## 关键问题

{列出所有 CRITICAL 和 HIGH 问题}

## 建议

{简要改进建议}
````

---

## 维度专项报告模板

适用于只检查某个维度：

```markdown
# {维度名称}审计报告

**项目**：{项目名称}
**时间**：{审计时间}

## 概览

{维度评分和问题统计}

## 问题列表

{按严重级别列出问题}

## 修复建议

{针对该维度的修复建议}
```

---

## 使用说明

1. 根据审计范围选择合适的模板
2. 全项目审计使用完整报告模板
3. 快速检查使用简洁报告模板
4. 单维度审计使用维度专项报告模板
5. 根据实际情况调整模板内容
6. 删除不适用的部分
